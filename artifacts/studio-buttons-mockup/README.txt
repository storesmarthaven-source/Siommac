SIOMAC Buttons Family — Studio-aligned HTML/CSS prototype

This version intentionally follows the styling already present in the three supplied SIOMAC Studio exports:
- 248px neutral white Studio rail
- existing breadcrumb/topbar proportions
- 22px Workbench heading
- 40px workbench tabs
- 300px sticky Properties rail
- neutral Studio chrome
- canonical SIOMAC navy/red button language

The UX change is only the family consolidation:
Buttons
  Action Button
  Dropdown Button
  Split Button

Each type still has its own Properties schema and semantic behavior.

The "Canonical defaults" option is shown as a future UI affordance only.
This static HTML/CSS prototype does NOT save app-wide component settings.
